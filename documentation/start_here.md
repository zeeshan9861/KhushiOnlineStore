## 🔧 Quick local preview (VS Code Live Server)

If you see the "Error loading products" message, it's usually because the page was opened via the filesystem (file://) and the browser blocked loading `products.json` with fetch.

Recommended (fastest): use the VS Code Live Server extension:

1. Open this project folder in Visual Studio Code.
2. Install the "Live Server" extension (by Ritwick Dey) if you don't have it already.
3. Open `index.html`, then either:
	- Click "Go Live" in the VS Code status bar, or
	- Right-click `index.html` → "Open with Live Server", or
	- Open the Command Palette (Ctrl+Shift+P) and run: "Live Server: Open with Live Server".
4. Live Server will open the site in your browser (usually at http://127.0.0.1:5500). The site will serve `products.json` correctly and the products will load.

Alternative (PowerShell):
```powershell
Set-Location 'e:\\Khushi Online Store'; python -m http.server 8000
```
Then open http://127.0.0.1:8000 in your browser.

Stop the server by closing the Live Server session (Go Live toggle) or pressing Ctrl+C in the PowerShell window.
