## How to Run

### Quick Start (Recommended)
1. Open VS Code
2. Right-click `index.html`
3. Select "Open with Live Server"
4. App opens at `http://localhost:5500`

### Alternative Methods
```bash

cd "e:\Khushi Online Store"
python -m http.server 8000

# Node.js
npx http-server
```

## Architecture Highlights

### OOP Design
```
AppController (Orchestrator)
├── ProductManager (manages products)
├── CartManager (manages cart)
├── ImageViewer (manages images)
├── UIRenderer (manages display)
└── Config (centralized configuration)
```

### Design Patterns Used
- Singleton (Config)
- Observer (Pub/Sub)
- MVC (Models, View, Controller)
- Service (Storage)
- Factory (Entity creation)
