## 🔄 HOW PRODUCTS SYNC TO MAIN WEBSITE

### Sync Process
```
Admin Console
    ↓
User adds/edits/deletes product
    ↓
Click "Sync" button
    ↓
Product saved to localStorage
    (khushi_products_sync)
    ↓
Go to Main Website (index.html)
    ↓
Website checks localStorage
    ↓
Loads products from localStorage
    ↓
✅ NEW PRODUCTS APPEAR!
```

### Important Notes
```
⚠️ Always click Sync after changes
⚠️ Reload main website to see updates
✅ Products persist across sessions
✅ Auto-sync happens on page refresh
```

## 🆘 TROUBLESHOOTING

### Issue: "Invalid email or password"
```
✅ Solution:
   → Check email spelling (admin@khushi.com)
   → Verify password (Khushi@12345)
   → Ensure caps lock is OFF
   → Try copy-pasting credentials
   → Try Gmail login instead
```

### Issue: Products not showing on main website
```
✅ Solution:
   → Click "Sync" button in admin console
   → Go to index.html (main website)
   → Refresh/reload page
   → Wait 1-2 seconds
   → Products should appear
```

### Issue: "You do not have permission to delete products"
```
✅ Solution:
   → You need Super Admin role
   → Login with admin@khushi.com
   → Or ask Super Admin to upgrade your role
   → Use console command to update role
```

### Issue: Can't login with "Remember Me"
```
✅ Solution:
   → Check browser cookies enabled
   → Don't manually clear localStorage
   → Try fresh login without Remember Me
   → Clear browser cache and retry
   → Check if session still exists:
      localStorage.getItem('khushi_admin_session')
```

### Issue: Forgot password
```
✅ Solution:
   → Contact: khushielectronics@gmail.com
   → Or reset via browser console:
      (See ADMIN_AUTHENTICATION_GUIDE.md)
```
