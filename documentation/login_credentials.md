## 🎯 COMMON TASKS

### Add a Product
```
1. Login with admin@khushi.com / Khushi@12345
2. Click "Add Product" tab
3. Fill form:
   - ID: Unique product ID
   - Name: Product name
   - Category: Select category
   - Price: Product price
   - Image: Image URL
   - Description: Product description
4. Click Submit
5. Click Sync button
6. Check main website (index.html)
```

### Edit a Product
```
1. Go to Products tab
2. Find product in list
3. Click "Edit" button
4. Update details
5. Click Save
6. Click Sync
```

### Delete a Product
```
1. Go to Products tab
2. Find product
3. Click "Delete" button (Super Admin only)
4. Confirm deletion
5. Click Sync
```

### Backup Products
```
1. Click Settings tab
2. Click "Backup" button
3. Done! (Auto-saved to localStorage)
```

### Export Products
```
1. Click Settings tab
2. Click "Export JSON"
3. JSON file downloads
4. Save to computer
```

### Import Products
```
1. Click Settings tab
2. Click "Import JSON"
3. Select JSON file
4. Click Open
5. Products imported!
```
